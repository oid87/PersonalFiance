限制（誠實揭露）：
- **美國沒有可靠的全市場每週融資維持率；NFCI-leverage 不是融資維持率**，它是金融狀況指數的槓桿子指數（含銀行、證券商、避險基金槓桿等指標，各自標準化），只能當「槓桿相關金融條件」的代理。
- **CFTC 持倉收縮不等於強制平倉**，也可能是主動降曝險、到期、換倉、跨商品對沖調整；TFF 的 Leveraged Funds 分類只含 CTA／避險基金等，不含全市場槓桿。
- **期貨轉倉**：季度到期週（第三個週五）與其後一週的 gross 曝險有機械性波動（實測：到期後一週 ES 槓桿基金 gross 中位 -14.5%、OI 中位 -20%）。本研究把這兩週的報告標記為轉倉污染、**不發訊號**，變動量改以「前一個乾淨報告 → 本報告」計算（跨週數記錄為 span，轉倉後第一個乾淨報告為 3 週變動）。CFTC consolidated 合約代碼（13874+、20974+、239742）混合不同契約規模，故全程用張數的**百分比變動**，不換算名目金額。
- **NFCI 歷史版本**：NFCI 每週重估整段歷史。本環境連不上 FRED／ALFRED（`fredgraph.csv` 逾時、官方 API 需 key），**無法取得 2020 起的逐期 vintage**，回測吃的是最新版；僅用 repo git 歷史做事後量測（下表），所以週資料的回測有「後見重估」風險，無法完全排除。
