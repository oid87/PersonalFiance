## 2. 固定參數（事前定案，沒有針對任何樣本調整）

| 參數 | 值 | 說明 |
|---|---|---|
| Stage A 波動極端 | VIX ≥ 30 或 VXN ≥ 35 | 來自需求清單的候選門檻；VXN 取 35 是因 VXN 結構上比 VIX 高約 1.2 倍（35/30≈1.17）。其他門檻見敏感度表 |
| PCR 極端 | Equity PCR 的 5 日均 ≥ 同口徑段內過去 504 日（約 2 年）的第 95 百分位 | 不含當日；至少 126 筆。5 年窗與 P90/P99 見變體表 |
| 回撤閘門 | 收盤距 120 日最高收盤 ≥ 8% | 與 usrisk 頁相同；同一天已發生的價格變化，不是底部預測 |
| 事件冷卻 | 10 個交易日 | 固定從第一個被接受的訊號起算；與既有 usrisk 引擎同定義。「首次觸發」＝每一波下跌（回撤 ≥8% 進入、<3% 結束）的第一個事件 |
| 進場與視窗 | 訊號日收盤後才知道 → 下一交易日開盤；視窗含進場日 | 報酬＝第 h 日收盤 / 進場開盤 − 1；h ∈ {5, 10, 20, 60, 120}；MAE＝視窗最低價 / 進場價 − 1（≤0）；MFE＝視窗最高價 / 進場價 − 1（≥0） |
| Stage C 止穩確認 | Stage A 事件後 40 個交易日內，同時滿足三項 | ① 近 5 日沒有創事件後新低收盤；② 波動指標 ≤ 事件後高點的 80%（SPY 用 VIX、QQQ 用 VXN）；③ 收盤站上 10 日均線。只用當日以前的資料 |
| Stage C 失敗辨識 | 確認日之後收盤跌破 Stage A 事件到確認日之間的最低收盤 | 回報距離確認日的交易日數與到那天為止相對進場開盤的損失 |
| 最低點距離 | 進場後 60 個交易日內的最低價 | 回報距進場的交易日數與相對進場開盤的百分比；視窗不足者不計 |

Model C、D（Down Volume）不可評估；Model E′ 以 Model B ＋ 止穩確認代替 Model D ＋ 止穩確認。
