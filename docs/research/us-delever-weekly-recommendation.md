# 美股去槓桿三層研究 — 結論與建議

數字來源：[us-delever-weekly-backtest.md](us-delever-weekly-backtest.md)（全部表格，含敏感度與兩個個案的逐週／逐日明細）。區間 2020-01-02～2026-10-16；SPY 下跌波段 8 個、QQQ 10 個（回撤≥8% 進入、<3% 結束）。引擎 `js/research/usdelever_*.mjs`，重現與獨立複核見文末。**沒有修改任何正式交易策略；沒有任何指標被預設有效。**

## 先說最重要的：這份研究「不能」證明什麼

- **沒有哪個週頻或月頻指標被證實能領先美股低點。** 樣本是 8～10 個波段、單一指標的獨立事件只有個位數到數十件，且事件彼此高度相關；所有「命中率」都是描述，不是檢定。
- CFTC 收縮不是強制平倉；**NFCI-leverage 不是融資維持率**（美國沒有可靠的全市場每週融資維持率）；FINRA 是月資料且公布晚。
- **NFCI 沒有取得 ALFRED 歷史版本**（本環境連不上 FRED／ALFRED）。回測用最新版數值。唯一的量測是 repo git 歷史的 3 個月版本差：NFCI／NFCIRISK／NFCICREDIT 的週變動修訂很小（最大約為週變動標準差的 0.08～0.16 倍），但 **NFCILEVERAGE 例外**：水準最大被改動 0.206（2026-07-03 該週），週變動最大修訂約 0.46 個標準差，是四個序列中最大的——所以本研究最依賴的 NFCI-leverage 週訊號，恰好最容易受後見重估影響。早年版本差未知。
- FINRA 公布日不是官方日曆，而是由 Wayback 快照括號＋緊括號月份的公布延遲（14～29 天，中位 22）推得；預設「月底+25 天」，並測最晚（上界）／最早（下界）兩端。
- 期貨轉倉會讓 gross 曝險機械性收縮（實測：季度到期後一週 ES 槓桿基金 gross 中位 -14.5%）。本研究把到期週與其後一週標為「轉倉污染」、不發訊號。

## 研究重點逐項回答

**A. 哪個每週指標最能反映去槓桿？ → 沒有一個夠好；有兩類只能算「同步的壓力表」。**
- CFTC 槓桿基金 gross 收縮與當週報酬幾乎無相關（|r|≈0.0～0.1，k=-4～+4 週全部無法與 0 區分）；ES 淨部位變動占 OI 與同週 SPY 報酬 r=-0.47，但那是槓桿基金（ES 多為淨空）在上漲時加空的結構，不是去槓桿。
- 「ES 與 NQ 同週 gross 收縮≥8%（集中）」精確度最高（SPY 67%／QQQ 83%，隨機基準 38%／48%），但只有 12 件事件，首次事件中位領先低點 26 個交易日（太早），近底命中 3/8、2/10。
- NFCI-leverage 週變動 z≥1.5 只有 7 件、命中 2/8，與市場報酬相關約 -0.07（無）；2026/7～8 個案期間它是**持續下降**（z 約 -2），不是上升。NFCI-risk／credit 與同週報酬相關 -0.33／-0.29（k=0），但它們含 VIX 與信用利差等市場變數，是**同步的壓力指標，不是領先指標**，也不是槓桿。

**B. 週資料是否比 FINRA 月資料更早發現風險？ → 結構上是（延遲 3～5 天 vs 約 25 天），但沒有證據顯示「更早到足以在低點前預警」。**
- FINRA 月減≥3% 事件的「近底」命中是 0/8（上界、下界、模型三種公布日都一樣），其公布時點在多數波段低點之後 12～45 個交易日（例如 2020/3 月減 -12.1% 約 4/25 才知道、低點在 3/23）。結論穩健：**月資料只能當確認**。
- CFTC 的最大收縮週出現在低點之前的有 2020/2、2022、2023/8、2024/7、2025/4 波段（領先 2～123 日），出現在低點之後的有 2020/9、2026/1 波段；ES∧NQ≥6% 近底命中 3/8（SPY）、2/10（QQQ）。時點不穩定，不能當可用領先指標。

**C. CFTC 持倉收縮放緩 ∧ VIX 回落之後，報酬與最大回撤？ → 沒有看到超過 VIX＋回撤條件本身的增量。**
- 放緩∧VIX 回落：17 件，SPY 20 日中位 +1.1%（基準：所有日 +1.8%、回撤≥5% +3.0%），60 日最大回撤中位 -4.6%；落在波段內的事件**全部發生在低點之後**（0 件在低點前）。
- 再加「SPY 回撤≥5%」：4 件（2020-04-13、2020-07-10、2022-12-02、2025-04-11），20 日 +4.3%／60 日 +9.3%（中位），但 4 件裡有 1 件（2022-12-02）20 日 -5.7%；n=4。
- 對照「僅 VIX 回落∧SPY 回撤≥8%」：11 件，20 日 +4.6%、60 日最大回撤中位 -5.1%——不含 CFTC 也一樣。所以「穩定階段」看起來是 VIX＋回撤的功勞，CFTC 放緩沒有明確附加價值（樣本太小也無法排除）。

**D. 日／週／月三層是否比單獨 VIX 更有辨識能力？ → 沒有。VIX≥30 單獨與三層確認相比，不輸。**
- VIX≥30：14 件、精確度 86%、波段命中 7/8、近底 4/8、20 日 SPY +3.0%／QQQ +3.0%，60 日最大回撤中位 SPY -5.9%／QQQ -8.3%。
- 三層確認 L3∧(L2∨L1)：13 件、精確度 62%、命中 5/8、近底 3/8、20 日 SPY +2.8%／QQQ +4.1%，60 日最大回撤中位 SPY -3.6%／QQQ -4.7%。回撤較小，但事件較少落在低點附近；這與「訊號出現得較晚」一致，不是更準。
- L3（5 項日頻壓力）單獨精確度 40%，與隨機基準 38% 無差；L3∧L2∧L1 只有 3 件，其後 20 日報酬中位 -8.0%（最大回撤 -14.5%）——n=3，只說明「三層全亮」不是買點。
- **兩個重點個案都不是 VIX-only 的好例子**：2024/7～8（SPY 低點 8/5、QQQ 8/7）：VIX 在 8/5 才到 38.6，之前 L3 項數 0～2；CFTC ES 單期 -5.9%（7/26 可得）、NQ -8.3%，未達集中門檻；FINRA 7 月 +0.2%、8 月 -1.7%（約 9/25 才公布）完全沒有警告。2026/7～8（QQQ 低點 7/29，SPY 回撤未達 8%）：VIX 最高只有 20.7、L3 最多 1 項、F&G 最低 24.7——**日頻 VIX 層完全沒有反應**；CFTC ES 在 6/30 報告有 3 週 -17.3% 的收縮（7/6 可得，約低點前 17 個交易日）；FINRA 7 月 -5.6% 在 8/19 前後才知道（低點後 3 週）。

**E. 能否輔助 SPY、QQQ 原型部位加碼？ → 只能當風險警示與「備戰」，不能當加碼訊號。**
- 沒有任何組合在 20 日報酬上穩定贏過「回撤≥5%／≥8% 的基準」（SPY +3.0%／+4.2%）；多數週／月訊號的警報後 20 日再破警報日低點比例仍高。
- 唯一值得保留的觀察：**VIX 回落 ∧ 指數仍有顯著回撤**（基準本身就已有 +3.0%～+4.6% 的 20 日中位），週頻資料沒有證明能把它變得更好。

## 恐懼貪婪（F&G<15）補充

- F&G<15 共 68 日（4.0%）；L3 日頻壓力在恐懼日 78%、非恐懼日 18%——但 F&G 本身含 VIX 成分，這是**同源重疊**，不是獨立證據。
- 週／月訊號事件日（含前 5 日）在恐懼區的比例低：ES∧NQ≥6% 4/18、FINRA 月減≥3% 3/13、NFCI-leverage 急升 1/7。2024/8 的 F&G 最低 16.6、2026/7 為 24.7，都**從未進入 <15**。恐懼區＝大跌後期，對「去槓桿開始」沒有領先性。

## 建議（供決定；未改動任何正式條件）

1. **把週／月資料定位為「背景與確認」**：FINRA 月減≥3%（公布後）＝槓桿已被迫收縮的確認；CFTC ES∧NQ 同週 gross 收縮≥8%（非轉倉週）＝短期壓力旗標。兩者都不當進場觸發。
2. **日頻保留 VIX≥30 為最簡單的壓力警示**；三層組合沒有證據優於它，不建議為了「看起來完整」而增加複雜度。
3. **別把 NFCI-leverage 當融資維持率或去槓桿指標**；若要用，只作「金融條件的背景」，並承認最新版數據有重估風險。
4. 兩個重點個案提醒：2026/7 這類 **QQQ／科技集中的回撤可以在 VIX 沒反應時發生**；需要另外的 QQQ 專屬指標（例如 VXN、廣度、F&G 以外的科技集中度）才有機會看到，現有三層不足。
5. 若要把這些觀察固化進正式流程，先補：(a) NFCI 逐期 vintage（需 FRED API key 或 ALFRED 可達的環境）；(b) FINRA 官方公布日曆；(c) 更多年份（2008～2019）檢驗，目前 8～10 個波段不足以下結論。

## 重現與複核

```bash
node scripts/research/backtest_us_delever.mjs --out docs/research/us-delever-weekly-backtest.md   # 含敏感度（FINRA 上/下界、CFTC/NFCI +1 日、收盤進場、冷卻 5/20）
python3 scripts/research/verify_us_delever.py     # Python 獨立重算並比對（波段、CFTC 轉倉與週變動、NFCI z、FINRA 事件、VIX 事件與報酬、L3 日數）
npm test                                          # 含 js/research/*.test.mjs
python3 scripts/research/fetch_cftc_tff_history.py       # 回補 2019～2021 CFTC TFF（CFTC 官方 zip）
python3 scripts/research/fetch_finra_release_dates.py    # Wayback 快照 → FINRA 公布日括號
python3 scripts/research/nfci_revision_probe.py          # git 歷史 → NFCI 重估量測
```

方法摘要：訊號「可得日」＝CFTC 報告日+3（週五，假日順延）／NFCI 週五+5（週三）／FINRA 模型公布日／日頻當日；事件＝同一訊號相隔 >10 個交易日；警報後表現＝可得日的**下一交易日開盤**進場，持有 5/10/20/60 日，最大回撤／反彈相對進場價，再破底＝持有期間最低價低於訊號日最低價；波段＝回撤（120 日高點）≥8% 進入、<3% 結束；命中＝波段（高點→結束）內出現過事件，精確度的比較基準＝隨機一天落在波段窗內的比例。
